# Formats and typography
| Deliverable | Pixels | Ratio |
|---|---:|---|
| Default portrait post / each carousel slide | 1080 × 1440 | 3:4 |
| Portrait alternative on request | 1080 × 1350 | 4:5 |
| Square on request | 1080 × 1080 | 1:1 |
| Story / poll story | 1080 × 1920 | 9:16 |
These are production presets, not claims about every platform's current upload limits. Respect the user's requested size. All slides in a carousel share dimensions.

Use 70–90 px side margins as an initial design guide. Stories: reserve roughly 250 px at the top and bottom for platform UI; inspect the actual placement instead of treating this as a guaranteed safe zone. Poll story: reserve a clean area about 800 × 600 px for a four-option sticker, preferably x=140,y=1000, away from products and footer. Adapt to actual sticker screenshot. The sticker itself is added in Instagram; never burn a fake interactive poll into final PNG. Guide boxes appear only in review mode.

Raleway variable is bundled under OFL for optional English use. Use the brand's chosen family consistently for headlines, labels and body. Typical 1080-wide sizes: headline 72–110 px, body 26–34 px, feature labels 18–24 px. Numeric features use lining numerals. Do not stretch lettering. Arabic requires a separately supplied/installed Arabic font with shaping support, RTL layout and visual QA. Do not pretend Raleway supplies Arabic glyphs.
